# Disputes, notifications, and sharing

## Disputes
- Any approved member may dispute any match.
- One open dispute per match; prevent duplicate open cases.
- Workflow: Open → Under review → Resolved or Dismissed.
- Member may add comments/supporting information to existing case.
- Notify session recorder and all admins; owner can see disputes in admin interface.
- Resolution choices: confirm existing result, correct score, or void match.
- Resolution reason required; preserve status, reason, comments, actor, timestamps and full history after closure.
- Dismissing dispute does not change result or ratings.
- While open, current result and ratings remain official but match is visibly marked disputed.
- If resolution changes score or voids match, trigger authorised correction/recalculation workflow.

## Notifications
- In-app notification centre only in V1; no email or browser push.
- Important events only: dispute updates, membership decisions, recorder handovers, session finalization/reopening.
- Read/unread state and unread count badge.
- Generate notification only after server-side event is confirmed.

## Session sharing
- After finalization, offer copyable WhatsApp-friendly summary; also allow sharing older completed sessions.
- Include date, match results, standings and selected key stats.
- Use verified stored results only; no account details or private links.
- No shareable leaderboard image in V1.
- AI-generated recap is deferred to Stage 3; if introduced, it may narrate verified stats only and cannot compute rankings or invent facts.
